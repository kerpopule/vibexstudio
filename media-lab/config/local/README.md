# config/local/ — this studio's own material (never committed)

Everything in this folder except this README is gitignored, never deployed
over and never deleted by `tools/deploy-spark.sh`. Put here what belongs to
one studio and not to the public project: extra looks, your own templates,
a known-character catalog, notes for Sparky.

The formats are in [docs/LOCAL-OVERLAY.md](../../docs/LOCAL-OVERLAY.md).
Per-host settings (addresses, paths, which licence-restricted engines are on)
go in `config/local.env` instead.
