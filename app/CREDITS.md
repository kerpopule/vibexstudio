# Credits

VibeXStudio is free and open source, and it exists because of other
people's work. Some attribution here is required by licenses; most is here
because we like giving credit.

- **Expo** and **React Native** (Meta) — the entire app foundation, with
  expo-router, expo-file-system, and the Expo Modules API (our iCloud sync
  bridge is a local Expo module).
- **Zustand** — state.
- **React Native WebView** — the live preview and the Media Lab surface.
- **AI providers** the user can bring: OpenRouter, Anthropic, OpenAI,
  Google Gemini, xAI, Z.ai, MiniMax, and Moonshot (Kimi). The MiniMax and
  Kimi device-code flows use the public client identifiers their own CLIs
  ship.
- **GitHub** — device-flow auth, the Git Data API, and GitHub Pages power
  the publish-and-share path.
- **Space Grotesk** by Florian Karsten and **Barlow** by Jeremy Tribby
  (SIL Open Font License) shape the web build's type.
- The NOIR visual language comes from our Co-Agent design system, itself
  descended from the gsgelato design work.
- Sync design lessons came from building MealReels' CloudKit sync — its
  gaps are why projects here sync as whole file trees via the iCloud
  Documents container.

If you see your work here uncredited, open an issue — we'll fix it.
