WEB ARCHITECTURE

Powerful without becoming a server farm.

The web editor does not need to run user apps on a VibeX server. Keep authoring client-side; use hosted infrastructure only for optional static publishing.

Local-first web studio

RECOMMENDED
  • IndexedDB / Origin Private File System for project files
  • Sandboxed iframe for static preview
  • Direct provider connection where browser CORS/OAuth permits
  • GitHub OAuth + Pages for user-owned publishing
  • No VibeX compute needed for normal authoring

Optional hosted lane

LATER / OPT-IN
  • Static assets only — never arbitrary server code
  • Short-lived publish tokens and strict path limits
  • Object storage + CDN before dedicated app servers
  • AWS can help scale publishing, not local creation
  • Accounts, billing, private apps require a separate approved architecture
